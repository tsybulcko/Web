Introduction to JavaScript

JavaScript ― это интерпретируемый язык программирования общего назначения с динамичуской типизацией данных.

Интерпретируемый значит, что программа выполняется в исходном виде, т.е. исходный код не преобразуется в машинный или промежуточный код. В связи с этим, ошибки на этапе компиляции и компоновки отсутстувют, есть только ошибки на этае выполнения. Интерпретатор JavaScript можно установить на любую ОС, что дает хорошую кроссплатформенность. Его иногда используют для разработки мобильных приложений под Android и в тестировании для написания скритов. Но чаще всего JavaScript используется для разработки WEB-приложений, а именно FrontEnd части WEB-риложения. Основным и самым расространенным интерпретатором его является самый обычный браузер.

Динамическая типизация говорит о том, что тип переменных и констант определяется во время присваивания по типу значения справа (r-value); Это означает, что у переменной нет как такогого постоянного типа данных. Наример, в переменную, которая хранит число, можно записать строку и она изменит свой тип. Это достигается благодаря тому, что абсолюдно все типы здесь являются объектами, а так же благодаря полиморфизму.

Переменные и типы данных

Переменные и константы

Переменную в JavaScript можно объявить с помощью ключевых слов var, let, const.

var
Объявляет глобальную переменную, несмотря на область видимости, в которой она объявлена. Если записать значение в несуществующую переменную, то это не вызовет ошибку, это будет аналогично ключевому слову 'var';
let
Объявляет локальную переменную, только для той области видимости, в которой она исользуется;
const
Объявляет константу. Контанты могут быть только локальными;

Типы данных:

Делятся на примитивные типы и объекты.

  1. Примитивные типы:
    • Boolean ― принимает одно из двух значений True либо False. Значения: 0, null, '', "", `` неявно преобразуются в False. True ― это любое значение, отличное от 0 или пустой строки.
    • String ― объект, описывающий массив символов
    • Number ― вещественное(дробное) число, которое является полным аналогом типа double. Все числовые литералы неявно преобразуются в Numder;
    • Bigint ― целое число неограниченных размеров
  2. Объекты:
    • Object ― объект;
    • Array ― массив;
    • Function ― функция;
    • Date ― дата, время;
    • Map ― контейнер;
    • Set ― контейнер;
    • RegExp ― регулярное выражение;
